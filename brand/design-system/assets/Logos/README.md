# Logos

- `taaj-lockup-light.svg` / `taaj-lockup-dark.svg` — bilingual lockup (taaj | تاج). Light = navy ink for light grounds; dark = ice ink for `abyss`/`night`.
- `taaj-wordmark-en-light.svg` / `-dark.svg` — English wordmark; the j's dot is the tooth-crown mark.
- `taaj-wordmark-ar-light.svg` / `-dark.svg` — Arabic wordmark; the two dots of ت are the tooth-crown mark.
- `taaj-icon.svg` — app icon and favicon, 512×512 tile.
- `taaj-mark.svg` — the tooth-crown mark alone.

Letters are Alexandria ExtraBold converted to outlines, so the files need no font.
